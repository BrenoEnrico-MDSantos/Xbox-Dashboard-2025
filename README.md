# 🎮 Xbox Sales Dashboard 2025
Dashboard criado para o desafio do Bootcamp DIO Santander Ciência de Dados 2025.
* 100% realizado no **Tableau Desktop** a partir do dataset [disponibilizado no bootcamp](https://github.com/BrenoEnrico-MDSantos/Xbox-Dashboard-2025/blob/main/805d54f9-6d53-4246-bed7-4aa2da615923.xlsx), o projeto apresenta dados fictícios relativos a um período de vendas, com enfoque em assinantes de diferentes planos e escolhas, para observaã de tendências de consumo e potencial _inbound marketing_.
* A visualização é totalmente dinâmica e faz uso de formatação customizada, **Campos Calculados**, **Ação** de _filter reset_ e um *Parâmetro* para troca de gráfico principal (Donut para Barra).
